# MiniRedis

A Mini Redis implementation written in Java.

## Goal

This project aims to learn

- Data Structures
- Object-Oriented Design
- In-Memory Storage
- Networking
- Concurrency
- Distributed Systems

## Roadmap

- [x] v0.1 SET / GET / DEL
- [x] v0.2 Persistence
- [x] v0.3 CLI
- [x] v0.4 TCP Server
- [x] v0.5 Multi Thread
- [x] v0.6 Replication
